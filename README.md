## Getting Started

1. Download/clone this repo
2. Install the dependencies with your package manager of choice:

```bash
npm install
# or
pnpm install
# or
yarn
# or
bun install
```

3. Run the development server:

```bash
npm run dev
# or
pnpm dev
# or
yarn dev
# or
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
